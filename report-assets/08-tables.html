TABLES

数据库表设计

共 10 张表，字段与实际建表 SQL（sql/init.sql）一致。
选中整页复制，粘到 Word 会自动保留表格结构。

用法：在浏览器打开本页 → Ctrl+A 全选 → Ctrl+C → 粘到 Word 目标位置，表格会直接成型，无需手画。

表 1edu_teacher讲师

字段类型可空默认值说明
id PKBIGINT否—讲师ID
nameVARCHAR(20)否—讲师姓名
introVARCHAR(500)是NULL讲师简介
careerVARCHAR(500)是NULL讲师资历/职业经历
levelTINYINT否11=讲师 2=高级讲师
avatarVARCHAR(500)是NULL头像URL（OSS）
sortINT否0排序，越小越前
gmt_createDATETIME否CURRENT_TIMESTAMP创建时间
gmt_modifiedDATETIME否CURRENT_TIMESTAMP更新时间
is_deletedTINYINT否0逻辑删除 0=正常 1=删除

索引：idx_name(name)

表 2edu_subject课程分类

字段类型可空默认值说明
id PKBIGINT否—分类ID
titleVARCHAR(20)否—分类名称
parent_idBIGINT否0父ID，0=一级分类
sortINT否0排序
gmt_createDATETIME否CURRENT_TIMESTAMP
gmt_modifiedDATETIME否CURRENT_TIMESTAMP

索引：idx_parent_id(parent_id)

表 3edu_course课程

字段类型可空默认值说明
id PKBIGINT否—课程ID
teacher_idBIGINT否—讲师ID
subject_idBIGINT否—二级分类ID
subject_parent_idBIGINT否—一级分类ID（冗余，便于筛选）
titleVARCHAR(50)否—课程标题
priceDECIMAL(10,2)否0.00价格
lesson_numINT否0课时数
coverVARCHAR(500)是NULL封面URL（OSS）
statusTINYINT否00=未发布 1=已发布
buy_countBIGINT否0购买数（演示用）
view_countBIGINT否0浏览数
gmt_createDATETIME否CURRENT_TIMESTAMP
gmt_modifiedDATETIME否CURRENT_TIMESTAMP
is_deletedTINYINT否0

索引：idx_teacher(teacher_id)；idx_subject(subject_id)；idx_parent(subject_parent_id)；idx_status(status)

表 4edu_course_description课程简介

字段类型可空默认值说明
id PKBIGINT否—简介ID
course_idBIGINT否—课程ID
descriptionTEXT是—课程详细介绍
gmt_createDATETIME否CURRENT_TIMESTAMP

索引：UNIQUE uk_course_id(course_id)

表 5edu_chapter课程章节

字段类型可空默认值说明
id PKBIGINT否—章节ID
course_idBIGINT否—课程ID
titleVARCHAR(50)否—章节标题
sortINT否0排序
gmt_createDATETIME否CURRENT_TIMESTAMP
gmt_modifiedDATETIME否CURRENT_TIMESTAMP

索引：idx_course(course_id)

表 6edu_section课程小节

字段类型可空默认值说明
id PKBIGINT否—小节ID
course_idBIGINT否—课程ID
chapter_idBIGINT否—章节ID
titleVARCHAR(50)否—小节标题
durationVARCHAR(20)是NULL时长，如 12:30
sortINT否0排序
gmt_createDATETIME否CURRENT_TIMESTAMP
gmt_modifiedDATETIME否CURRENT_TIMESTAMP

索引：idx_chapter(chapter_id)；idx_course(course_id)

表 7crm_banner首页轮播

表 10sys_login_log登录日志

字段类型可空默认值说明
id PKBIGINT否—主键
usernameVARCHAR(50)否—登录名
user_typeVARCHAR(10)否adminadmin/member
ipVARCHAR(50)是NULL登录IP
user_agentVARCHAR(500)是NULLUA
successTINYINT否11=成功 0=失败
login_timeDATETIME否CURRENT_TIMESTAMP

索引：idx_username(username)；idx_time(login_time)
