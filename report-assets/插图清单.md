## 图 4 类图（已由 IDEA 生成）

`out/图4-类图.png` —— 3850×3946px，白底，652dpi，插 15cm 宽正好 15.4cm 高。

生成方式（留档，答辩可能问）：

```
Project 面板 → src/main/java/com/guli
多选 controller / service / mapper / entity
右键 → Diagrams → Show Diagram…（Ctrl+Alt+Shift+U）
图内右键 → Show Categories 勾 Fields / Methods / Dependencies
图内右键 → Layout → Hierarchical
右上 Export Diagram → PNG
```

导出后另存为 `report-assets/out/图4-类图.png`，编号对得上。
